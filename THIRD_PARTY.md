# Third-party components

Era-SGF's original sources are MIT-licensed. No GOReader or KOReader implementation is included.

## GCC runtime libraries in PocketBook builds

The default PocketBook build statically links GCC's `libstdc++` and `libgcc` so the application's
C++ runtime does not depend on a newer `libstdc++.so` being installed on the reader. These
libraries are covered by GPLv3 with the GCC Runtime Library Exception, version 3.1.
The applicable texts are included in `LICENSES/` and in the installable package.

- [GCC license](https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html)
- [Runtime exception](https://www.gnu.org/licenses/gcc-exception-3.1.html)

The standard build uses the unmodified compiler from the public PocketBook SDK. Host tools
use the host system's compiler and libraries.

## PocketBook SDK and InkView

The SDK is downloaded separately from the publisher's [release](https://github.com/pocketbook/SDK_6.3.0/releases/tag/6.8).
SDK headers, compilers and shared libraries are not included in this source repository or in
the application's installable archive. The viewer dynamically links the InkView and system
libraries supplied by PocketBook firmware. Their terms remain separate from the Era-SGF license.

## Synthetic records and codec mappings

Records in `examples/` and `tests/fixtures/` are synthetic examples created for this project.
The single-byte Unicode mappings are generated by `tools/generate_codecs.py` from the Python
standard library's codec mappings; no Python runtime is shipped on the reader.

## zlib for PNG screenshots

PNG screenshot compression uses unmodified zlib from the PocketBook SDK, statically linked
by the canonical ARM build. Host builds use system zlib. See LICENSES/Zlib.txt for its notice.

## Distribution audit (2026-11-02)

The shipped third-party code is zlib and the GCC runtime. zlib permits redistribution
and commercial use subject to its notice conditions; GCC's Runtime Library Exception
permits eligible compiled combinations with independent modules under their own terms.
No extra parser/UI/PNG library is bundled. See [zlib terms](https://www.zlib.net/zlib_license.html)
and [GCC terms](https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html).

The original code and code-generated Book/vector artwork are under the project's MIT
license. Host test/emulator dependencies are not part of the reader release. Only synthetic
SGF examples ship; the owner's personal game collection is excluded. Firmware fonts
and InkView remain on the reader and are not redistributed in our archive.

## InkView follow-up (2026-11-02)

The initial audit overstated the need to obtain individual permission before distributing
Era-SGF. No such requirement or specific prohibition was established by the reviewed material.
There is substantial primary-source evidence of publicly distributed third-party InkView
applications: CoolReader (GPLv2), KOReader (AGPLv3), and Pocketbook-OPDSClient (MIT).
PocketBook Free also historically published SDK-built applications and allowed contest
participants to specify their own application license.

This supports treating our independently written application as a normal third-party
PocketBook application, while retaining MIT for our code and omitting SDK/firmware binaries
from our package. This is a practical assessment of the evidence, not a newly discovered
license grant or an assertion that InkView itself is MIT/GPL. No standalone InkView 6.8
redistribution license was found. Written clarification from PocketBook could resolve that
remaining documentation uncertainty; it has not been established as a mandatory release step.

See [the investigation and primary sources](docs/inkview-licensing.md). The audit does not
cover repackaging or distributing the SDK, emulator, or libinkview.so itself.
