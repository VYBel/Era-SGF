# Era-SGF

Самостоятельный просмотрщик SGF для электронных книг PocketBook.
Первая целевая модель — **PocketBook Era 700**; проект рассчитан и на другие модели с PocketBook OS / Linux.

[English](README.md) · [Установка](docs/install.md) · [Сборка](docs/build.md) · [Проверки](docs/validation.md) · [Участие в разработке](CONTRIBUTING.md)

## Состояние проекта

**Версия 1.2.4**: открытие SGF и последней позиции без загрузки всего каталога,
компактный индекс случайных непросмотренных партий и ограниченный поиск отсутствующих
файлов. Сканирование запускается явно, отметки просмотра сохраняются.
Проверено с каталогом из 117 309 партий; [замеры и ограничения](docs/library-performance.md).
[Скачать готовую сборку](https://github.com/VYBel/Era-SGF/releases/tag/v1.2.4).
Интерфейс приложения — на русском языке.

Нативное приложение на InkView SDK запускается из меню книги и умеет регистрировать
ассоциацию `.sgf`. Установка KOReader не требуется. Сборка B288 рассчитана на
прошивку **6.8+**; видимость нового формата в штатной библиотеке нужно проверить на книге.

## Возможности

- Открытие локальных SGF, доски 9×9, 13×13 и 19×19.
- Переходы по ходам, выбор вариантов и возврат к развилке.
- Под доской: начало, −10 ходов, ввод номера, +10 и конец выбранной ветки.
- Комментарии, сведения о партии, буквенные метки и обозначения на доске.
- Управление касаниями и физическими кнопками перелистывания.
- Запоминание текущего хода, выбранной ветки и кодировки при закрытии или скрытии приложения.
- UTF-8, Windows-1251, KOI8-R, CP866 и ISO-8859-5 для русских комментариев.
- Учёт `CA[...]` в SGF, автоопределение и ручной выбор кодировки.
- Полноэкранная библиотека: вкладки Все / Новые / Просмотренные, год, поиск и страницы.
- Случайная непросмотренная партия одним нажатием, без влияния текущих фильтров.
- Отметка просмотра, перенос в `sgf/viewed/<год>/` с сохранением позиции и удаление с подтверждением.
- Автолистание с паузой 3 секунды по умолчанию и обязательной остановкой на развилке.
- Настраиваемая полная очистка экрана: 5/10/20/50 изменений или вручную, кнопка справа вверху.
- Снимок позиции в PNG и семь вариантов чёрно-белого знака при запуске.
- Подписи цветов игроков, увеличенная доска и отсутствие пустых комментариев.
- Результат в конце основной линии, кнопка информации о партии и окно «О программе».

В статичном просмотре приложение не запускает периодические таймеры, пересканирование
библиотеки или сетевые операции. Таймер автолистания существует только при включённом
режиме. Реальный расход батареи зависит также от прошивки и подсветки и требует измерения.

Исходный SGF при просмотре не изменяется. Редактирование, сетевая игра и анализ движком
в первую версию не входят.

## Совместимость

Интерфейс должен подстраиваться под размер экрана и доступные кнопки. Один исполняемый
файл не обещается для всех моделей: разные ABI и прошивки могут потребовать отдельных сборок.

| Устройство | Состояние |
| --- | --- |
| PocketBook Era 700 | Основная модель; предрелизные сборки испытывались владельцем, детали — в отчёте проверок |
| Другие PocketBook с PocketBook OS / Linux | Запланировано; пока не проверено |
| Устройства на Android | За пределами первоначальной платформы |

Подтверждённую совместимость будем отмечать с моделью, версией прошивки и версией приложения.

## Установка и сборка

Скачай **Era-SGF-1.2.4-b288.zip** со [страницы релиза](https://github.com/VYBel/Era-SGF/releases/tag/v1.2.4).
Для обычной установки распакуй архив в корень памяти книги, безопасно отключи USB
и запусти `era-sgf` из приложений. SDK и компилятор пользователю не нужны.
Для значка в разделе «Игры» используй приложенный к релизу установщик для Linux/POSIX;
порядок действий приведён в [инструкции установки](docs/install.md).

Сборка из исходников в Linux:

```sh
make test all
bash scripts/setup-sdk.sh
make package
```

SDK занимает около 1,3 ГБ в архиве и хранится вне Git; требования указаны в [инструкции сборки](docs/build.md).
Архив содержит один `.app`, два BMP-значка, учебные SGF и лицензии.
[Установщик для компьютера](docs/desktop-integration.md) делает резервную копию и добавляет
значок «Книга» в раздел «Игры» рядом с шахматами. Обычная распаковка ZIP устанавливает
приложение без регистрации в этом разделе. Ассоциация `.sgf` добавляется через
«Настройки → Ассоциация SGF» в приложении с резервной копией `extensions.cfg`.
Подробности и удаление описаны в [инструкции установки](docs/install.md).
Старые ярлыки `era-sgf-install.app` и `era-sgf-uninstall.app` при обновлении можно удалить.

Используются C++14, официальный компилятор GCC 6.3 из SDK, Make или дополнительный CMake
и PocketBook InkView. Разбор SGF, кодировки, навигация и обработка событий проверяются
на компьютере. Работа дисплея и интеграция с прошивкой проверяются отдельно на книге;
текущее состояние отражено в [отчёте](docs/validation.md).

Для интерактивной проверки интерфейса в Linux есть [официальный SDK-эмулятор](docs/emulator.md):
`make emulator`. Он использует отдельную локальную память и не обращается к подключённой книге.
