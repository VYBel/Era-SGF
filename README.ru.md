# Era-SGF

Самостоятельный просмотрщик SGF для электронных книг PocketBook.
Первая целевая модель — **PocketBook Era 700**; проект рассчитан и на другие модели с PocketBook OS / Linux.

[English](README.md) · [Проектное решение](docs/design.md) · [Участие в разработке](CONTRIBUTING.md)

## Состояние проекта

**Начальная подготовка и проектирование. Рабочего приложения и установочного выпуска пока нет.**

Планируется нативное приложение на InkView SDK, которое запускается из меню книги и
открывает `.sgf` по ассоциации файлов. Установка KOReader не требуется.

## Первая версия

- Открытие локальных SGF, доски 9×9, 13×13 и 19×19.
- Переходы по ходам, выбор вариантов и возврат к развилке.
- Комментарии, сведения о партии, буквенные метки и обозначения на доске.
- Управление касаниями и физическими кнопками перелистывания.
- Запоминание текущего хода, выбранной ветки и кодировки.
- UTF-8, Windows-1251, KOI8-R, CP866 и ISO-8859-5 для русских комментариев.
- Учёт `CA[...]` в SGF, автоопределение и ручной выбор кодировки.

Исходный SGF при просмотре не изменяется. Редактирование, сетевая игра и анализ движком
в первую версию не входят.

## Совместимость

Интерфейс должен подстраиваться под размер экрана и доступные кнопки. Один исполняемый
файл не обещается для всех моделей: разные ABI и прошивки могут потребовать отдельных сборок.

| Устройство | Состояние |
| --- | --- |
| PocketBook Era 700 | Основная цель; на устройстве пока не проверено |
| Другие PocketBook с PocketBook OS / Linux | Запланировано; пока не проверено |
| Устройства на Android | За пределами первоначальной платформы |

Подтверждённую совместимость будем отмечать с моделью, версией прошивки и версией приложения.

## Установка и сборка

Готового выпуска пока нет. Проверенные команды установки появятся вместе с первой сборкой.
Планируется пакет с `.app`, ресурсами и отдельным установщиком ассоциации `.sgf`, который
сохраняет остальные записи и делает резервную копию `extensions.cfg`.

Предложенный стек — C++17, CMake и PocketBook InkView. Разбор SGF, кодировки и навигация
проверяются на компьютере; запуск, кнопки, экран и ассоциация — отдельно на книге.
Подробности и критерии готовности описаны в [проектном решении](docs/design.md).
