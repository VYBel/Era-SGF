# Era-SGF 1.1.0 screenshots

Captured from the official B288 x86-64 InkView SDK emulator at 1264×1680.
These are real application frames, not UI mockups. All displayed SGFs are
synthetic two-move test records; player names illustrate text layout and do not
identify historical games. The firmware determines native popup menu styling.
Physical E Ink refresh behavior is not reproduced by this emulator.
