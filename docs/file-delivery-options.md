# Доставка SGF на PocketBook: варианты

Предложения от 2026-11-02. Последующее решение владельца: пока ничего не реализовывать;
предпочтительное направление — собственный сервис, без Telegram-клиента на книге и без Dropbox.
Ниже сохранены рассмотренные варианты, а не утверждённый план разработки.

## Рассмотренный вариант: личный сервис и Telegram как вход

Пользователь отправляет SGF боту → небольшой сервис сохраняет файл в личную
очередь → в Era-SGF пользователь нажимает «Получить партии» → приложение
скачивает новые партии в `sgf/inbox/` и обновляет каталог. Альтернативный вход
в ту же очередь — простая веб-страница с загрузкой файла.

Telegram Bot API позволяет получать документы и скачивать их через getFile.
В публичном Bot API лимит скачивания — 20 МБ. URL скачивания содержит токен
бота, поэтому с Telegram общается сервер, а не книга.
Источник: [официальный Bot API](https://core.telegram.org/bots/api#getfile).

Предлагаемое поведение:

- Получение только по запросу: никаких фоновых таймеров и опроса сети при чтении.
- На книге отдельный отзываемый ключ устройства; токен бота остаётся на сервере.
- Бот принимает файлы только от разрешённого Telegram user ID.
- Проверка размера и SGF; сохранение исходных байтов, включая старую кодировку.
- Безопасное локальное имя, уникальные имена при коллизии и исключение дублей
  по содержимому; повторная попытка не должна вернуть уже просмотренную партию.
- Загрузка во временный файл, проверка полноты, затем атомарное сохранение.
  Подтверждение получения — после успешной записи на книгу.
- Ошибка Wi-Fi не мешает открывать уже загруженные партии.

Сначала нужен небольшой технический опыт на Era: подключение к HTTPS с проверкой
сертификата, тайм-ауты, прерывание и восстановление после обрыва. Только затем
имеет смысл выбирать стек и точный API существующего личного сервиса. Совместимость
его текущего TLS с прошивкой пока не проверена.

## Альтернативы

| Вариант | Пользовательский сценарий | Ограничение |
|---|---|---|
| Личный сервис без Telegram | Загрузить SGF через веб-страницу, забрать кнопкой в приложении | Нужен небольшой сервер; меньше внешних зависимостей |
| Telegram + личный сервис | Отправить файл боту, забрать на книге | Удобнее с телефона, но файл проходит через Telegram |
| Встроенный Dropbox PocketBook | Положить файл в папку Dropbox PocketBook и синхронизировать | Нужен аккаунт; доставку именно `.sgf` необходимо сначала проверить |
| Send-to-PocketBook | Отправить вложение на адрес книги | Документация описывает книги, поддержку SGF не подтверждает |

Руководство Era описывает Dropbox, его отдельную папку и ручную синхронизацию,
а также получение вложений через Send-to-PocketBook. Это подтверждает наличие
сервисов, но не результат доставки нашего формата на конкретную прошивку.
Источник: [официальное руководство Era, раздел Services, стр.48–54](https://support.pocketbook-int.com/fw/700/u/6.8.3713/manual/User_Manual_Era_EN.pdf).

Для публичного Era-SGF адрес сервера должен быть настраиваемым; обязательной
зависимости от личного сервиса владельца проекта быть не должно. Сетевое получение
остаётся необязательным дополнением к локальным файлам.
