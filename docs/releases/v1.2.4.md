# Era-SGF 1.2.4 — быстрый запуск и случайные партии

Исправления для больших коллекций после релиза 1.2.0. Era-SGF — самостоятельное
приложение для PocketBook; KOReader не требуется.

## Что изменилось

- Отдельный SGF из штатной библиотеки открывается без чтения всего каталога Era-SGF
  и без заставки. Повторный запуск восстанавливает последнюю позицию без загрузки базы.
- Полный каталог загружается только при открытии библиотеки с фильтрами или файловых
  операциях, которым он нужен. Есть прогресс, отмена и пауза при скрытии приложения.
- Случайная непросмотренная партия выбирается по компактному индексу без загрузки
  всех метаданных. Учитываются отметки просмотра и файлы, открытые отдельно.
- Удалённые файлы пропускаются. Перебор ограничен 32 проверками и бюджетом 250 мс
  между проверками; отдельное системное чтение этим бюджетом не прерывается.
  Если доступная партия не найдена, предлагается обновить список, фоновых повторов нет.
- Открытые файлы и отметки надёжно сохраняются до загрузки каталога, затем объединяются
  с ним. Повтор после прерывания не сбрасывает отметки; повреждённый каталог не
  заменяется базой из одной открытой партии.
- Обход папок и пересканирование SGF запускаются только явно. В статическом просмотре
  нет периодических таймеров; завершение диалогов возвращает приложение в ожидание.

## Установка и обновление

Готовая сборка **B288 / ARMv7 soft-float**, прежде всего для **PocketBook Era 700**,
прошивки **6.8+**. Другие модели требуют отдельной проверки.

1. Сохрани на компьютере **всю папку `system/config/era-sgf`** и прежний `.app`.
2. Скачай `Era-SGF-1.2.4-b288.zip`. Распакуй в корень памяти книги с объединением
   папок либо используй приложенный установщик `install-mounted-reader.py`
   для значка в разделе «Игры» — [инструкция](https://github.com/VYBel/Era-SGF/blob/v1.2.4/docs/install.md).
3. Безопасно отключи USB. После обновления со старого релиза **один раз выбери
   «Библиотека партий → ⋯ → Обновить список партий»**, чтобы построить индекс
   случайного выбора. На большом архиве это может занять время. При последующих
   запусках обновление автоматически не повторяется.
4. После внешнего добавления, удаления или изменения SGF обновляй список той же
   командой. Открытый напрямую SGF регистрируется без пересканирования архива.

Для проверки архива скачай рядом `.zip.sha256` и выполни:

```sh
sha256sum --check Era-SGF-1.2.4-b288.zip.sha256
```

**Откат:** восстанови прежнее приложение и прежнюю папку состояния. Версии до 1.2.2
не читают отложенные записи, а 1.1.1 — каталог v2. Резервная копия файлов установщика
не заменяет копию пользовательского состояния; новые отметки в старой копии отсутствуют.

## Проверки

- 165 проверок: ядро, интерфейс, библиотека, файловые операции, упаковка и установщик;
  также ASan/UBSan. ARM-сборка установлена на Era 700 и сверена после записи.
- На каталоге из **117 309 партий** хостовая проверка случайного выбора: около 5 мс,
  пик RSS около 11,4 МиБ, без обхода папок архива. Это локальная копия индекса на
  компьютере и проверка выбранного файла через USB, **не замер процессора Era**.
- Пользователь подтвердил быстрый запуск на книге со всем архивом. Последние изменения
  случайного выбора проверены программно; физический тест этих изменений остаётся отдельным.
- Новых зависимостей нет. Исходники — MIT; сведения о компонентах и InkView включены
  в `THIRD_PARTY-Era-SGF.md`. В архиве только приложение, иконки, учебные примеры,
  инструкция и лицензии; личные коллекции, состояние устройства и SDK не включены.
