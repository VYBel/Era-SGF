**Era-SGF 1.1.0** — обновление библиотеки и меню для PocketBook.

### Что изменилось

- Полноэкранная библиотека: Все / Новые / Просмотренные, поиск, год, строки с игроками
  и датой, страницы и управление кнопками книги. В меню ⋯ — обновление, открытие SGF
  из папки и сброс фильтров.
- «Случайная новая партия» выбирает непросмотренный файл по всей библиотеке,
  независимо от фильтров. Если все просмотрены, приложение сообщает об этом.
  Пустые и повреждённые коллекции имеют отдельные сообщения.
- Главное меню из шести пунктов, файловые операции внутри «Текущая партия». ← возвращает на уровень выше; закрытие ведёт к доске.
  Выбор паузы, кодировки и очистки экрана возвращает в настройки.
- Включены исправления локальной 1.0.2: защита автоплея от автоблокировки/выключения,
  восстановление после возврата из сна и заметные хоси.

### Скачать

**`Era-SGF-1.1.0-b288.zip` — готовое скомпилированное приложение.**
Скачивай его в Assets ниже. Автоматические архивы GitHub «Source code» содержат
исходники и не подходят для обычной установки на книгу.

Также приложены:

- `install-mounted-reader.py` — необязательный установщик для Linux/POSIX,
  добавляющий значок в «Игры» и сохраняющий резервные копии;
- `SHA256SUMS.txt` и `Era-SGF-1.1.0-b288.zip.sha256` — контрольные суммы.

### Установка

1. Подключи PocketBook по USB в режиме передачи файлов.
2. Распакуй **содержимое ZIP в корень памяти книги**, объединив папки.
   Должен получиться путь `applications/era-sgf.app`.
3. Безопасно отключи USB и запусти `era-sgf` из приложений.
4. Открой учебную партию `Books/Era-SGF/first-steps.sgf` через меню приложения.
   Собственные SGF можно складывать в `sgf/`, включая подпапки по годам.
5. Для открытия SGF из штатной библиотеки выбери
   **Меню → Настройки → Ассоциация SGF → Связать .sgf с Era-SGF**.
   Существующая конфигурация сохраняется в резервную копию. Распознавание нового
   формата штатной библиотекой зависит от прошивки; файловый браузер Era-SGF
   доступен независимо от неё.

SDK и компилятор пользователю не нужны. Для обновления можно повторно распаковать
ZIP поверх предыдущей версии; настройки и партии в архив не входят.

### Значок в разделе «Игры»

На Linux/POSIX сохрани ZIP и `install-mounted-reader.py` в одну папку **на компьютере**.
Нужен Python 3.9+. Замени `/path/to/PocketBook` на точку монтирования книги.
Сначала просмотр плана:

```sh
python3 install-mounted-reader.py --root /path/to/PocketBook --archive Era-SGF-1.1.0-b288.zip --backup-dir ./era-sgf-backups
```

Затем установка с сохранением резервных копий на компьютере:

```sh
python3 install-mounted-reader.py --root /path/to/PocketBook --archive Era-SGF-1.1.0-b288.zip --backup-dir ./era-sgf-backups --apply
```

Без этого шага приложение доступно в пользовательском разделе приложений.
После установки безопасно отключи USB. Не копируй Python-скрипт в приложения книги.

### Возможности

Ветки SGF, полноэкранные комментарии, информация о партии и её результат;
кодировки UTF-8, Windows-1251, KOI8-R, CP866 и ISO-8859-5; переходы ±10 и к номеру
хода, сохранение позиции; каталог с поиском, годами и фильтром просмотренных;
перенос и удаление с подтверждением; автолистание с остановкой на развилке;
PNG-снимки; настройка очистки E Ink и ручная кнопка обновления.

### Совместимость и ограничения

Основная модель — **PocketBook Era 700**. Сборка: **B288, ARMv7 soft-float,
PocketBook OS/Linux, SDK 6.8**, целевые совместимые прошивки 6.8+.
Универсальная работа на всех моделях не обещается. Интерфейс сейчас на русском.
Сетевой загрузки, редактирования SGF и анализа движком нет.

Собственные исходники — MIT. SDK/InkView в архив не включены; приложение использует
библиотеку из прошивки. Уведомления zlib и GCC Runtime входят в архив.
