# Установка / Installation

## Первая проверка на PocketBook

Первая экспериментальная сборка предназначена для PocketBook OS / Linux, платформы B288
и прошивок 6.8+. Основная целевая модель — Era 700. Подтверждённой проверки на физической
книге пока нет; текущие результаты приведены в [отчёте](validation.md).

1. Собери ZIP по [инструкции](build.md) или получи экспериментальный архив проекта.
2. Подключи книгу по USB и распакуй содержимое архива в корень доступной памяти.
   Папки `applications/` и `Books/` нужно объединить с существующими. SDK на книгу не копируется.
3. Безопасно отключи USB и запусти `era-sgf` из меню приложений.
4. Через «Меню → Открыть SGF» открой `Books/Era-SGF/first-steps.sgf`.
   Проверь доску, листание ходов, два продолжения и комментарии.
5. Проверь `Books/Era-SGF/windows-1251.sgf`: русский текст должен читаться без конвертации файла.
6. Для ассоциации запусти `era-sgf-install` либо выбери «Связать файлы .sgf с Era-SGF» в меню.
   Это отдельное явное действие: обычное открытие партии ассоциации не меняет.
7. Закрой и открой штатную библиотеку, затем попробуй открыть SGF непосредственно из неё.

Если новая ассоциация ещё не делает SGF видимыми в штатной библиотеке, используй файловое
меню Era-SGF и сообщи модель/версию прошивки. Поведение сканера библиотеки и передача пути
новому обработчику должны быть подтверждены на конкретной прошивке.

Установщик добавляет `era-sgf.app` в обработчики SGF в `system/config/extensions.cfg`,
сохраняя остальные форматы и другие SGF-программы. Перед изменением существующий файл
копируется в `extensions.cfg.era-sgf.bak` (или следующий свободный номер).
Символическая ссылка вместо конфигурационного файла не перезаписывается.

## Управление

- Кнопки перелистывания: предыдущий/следующий узел записи, включая узлы с комментариями.
- «Ветки»: список продолжений. При нескольких вариантах первые десять отмечаются числами на доске.
- «К предыдущей развилке», «В начало», «В конец выбранной ветки»: пункты меню.
- Нажатие на заголовок комментария или соответствующий пункт меню: чтение на весь экран.
  В этом режиме кнопки листают страницы комментария; «Назад» возвращает к доске.
- «Выбрать партию»: игры внутри SGF-коллекции.
- «Информация о партии»: игроки, дата, результат, коми и общий комментарий, если они есть в файле.
- «Повернуть экран»: ручная смена ориентации.

Позиция и ручная кодировка сохраняются при закрытии, скрытии приложения или переходе к другому
файлу. После замены содержимого SGF сохранённая позиция сбрасывается. Исходные SGF не изменяются.

## Кодировки

«Авто» сначала учитывает SGF `CA[...]`. Если его нет, проверяется UTF-8, затем применяются
осторожные эвристики для русских однобайтных кодировок. Для неоднозначного текста используется
стандартный SGF-вариант ISO-8859-1 с отметкой неопределённости.

Если комментарий нечитаем или `CA` указан неверно, открой «Меню → Кодировка» и выбери UTF-8,
Windows-1251, KOI8-R, CP866, ISO-8859-5 или ISO-8859-1. Ручной выбор имеет приоритет над `CA`.
«Авто» отменяет его. В SGF-коллекции переход к другой партии снова учитывает её собственный `CA`.

Кодировки UTF-16/32 и дополнительные восточноазиатские однобайтные/многобайтные кодировки
в первоначальную версию не входят. Неподдерживаемое объявление или неверные байты отображаются
как ошибка с возможностью выбрать поддерживаемую кодировку; приложение не переписывает файл.

## Удаление и откат

Сначала запусти `era-sgf-uninstall` или выбери удаление ассоциации в меню приложения.
Удаляется только обработчик Era-SGF; другие SGF-обработчики остаются. Затем можно удалить
три файла `era-sgf*.app` из `applications/` и учебную папку `Books/Era-SGF/`.

Настройки просмотра остаются в `system/config/era-sgf/`; их можно удалить отдельно.
Резервные копии ассоциаций сохраняются рядом с `extensions.cfg`. Восстановление целой копии
заменит и более поздние изменения других программ, поэтому для обычного удаления предпочтителен
штатный пункт удаления ассоциации.

## English quick start

Extract the experimental ZIP into the reader's USB storage root, merging `applications/`
and `Books/`. Eject safely and launch `era-sgf` from Applications. Use its Open SGF menu
to test the bundled examples. Run `era-sgf-install` explicitly to register `.sgf` files;
the existing configuration is backed up. Close and reopen the stock library and test opening
an SGF from there. Stock-library integration and actual hardware behavior remain unverified.

The UI is currently Russian. Page-turn keys navigate nodes, the Branches button selects a
variation, the comment heading expands text, and Menu → Кодировка changes encoding.
Use `era-sgf-uninstall` before deleting the three application files. See [build.md](build.md)
and [validation.md](validation.md) for the build profile and current limits.
