# Установка / Installation

## Готовая сборка 1.2.0

Перед обновлением скопируй всю папку `system/config/era-sgf` с книги на компьютер.
Версия 1.2.0 переносит каталог v1 в v2 с сохранением отметок просмотра. Для отката
на 1.1.1 понадобится прежняя папка состояния вместе с прежним приложением:
старая версия не читает каталог v2. Резервная копия файлов установщика не заменяет
эту копию пользовательского состояния.

Платформа: PocketBook OS / Linux, B288, ARMv7 soft-float, SDK 6.8 (прошивки 6.8+).
Основная модель — Era 700. Совместимость с другими моделями и интеграция формата
в штатную библиотеку проверяются отдельно; см. [отчёт](validation.md).

Со [страницы релиза v1.2.0](https://github.com/VYBel/Era-SGF/releases/tag/v1.2.0)
скачай `Era-SGF-1.2.0-b288.zip`. Архив уже содержит скомпилированное приложение.
SDK, компилятор и Python на самой книге не нужны.

### Обычная установка — любой компьютер

1. Подключи книгу по USB в режиме передачи файлов.
2. Распакуй содержимое ZIP **в корень памяти книги**, объединив папки. Должен
   получиться путь `applications/era-sgf.app`, без дополнительной папки с именем архива.
   При обновлении можно заранее сохранить старый `.app` на компьютер.
3. Безопасно отключи USB и запусти `era-sgf` из пользовательских приложений.
4. Открой «Меню → Текущая партия → Файл и отметка просмотра → Открыть SGF» (при отсутствии партии — «Открыть SGF»)
   и выбери `Books/Era-SGF/first-steps.sgf`. Второй пример,
   `Books/Era-SGF/windows-1251.sgf`, проверяет русские комментарии в старой кодировке.
5. Для ассоциации выбери «Меню → Настройки → Ассоциация SGF → Связать .sgf с Era-SGF».
   Закрой и открой штатную библиотеку, затем попробуй открыть SGF из неё.

### Значок в разделе «Игры» — установщик для Linux/POSIX

Скачай также `install-mounted-reader.py` из вложений того же релиза. Нужен
Python 3.9+ **на компьютере**. Сохрани скрипт и ZIP в одной папке на компьютере,
открой в ней терминал. В командах замени `/path/to/PocketBook` на точку монтирования книги:

```sh
python3 install-mounted-reader.py --root /path/to/PocketBook --archive Era-SGF-1.2.0-b288.zip --backup-dir ./era-sgf-backups
```

Первая команда только показывает план. Для установки:

```sh
python3 install-mounted-reader.py --root /path/to/PocketBook --archive Era-SGF-1.2.0-b288.zip --backup-dir ./era-sgf-backups --apply
```

Установщик сохраняет заменяемые файлы в `era-sgf-backups/` **на компьютере**,
проверяет запись и добавляет «Книгу» в раздел «Игры» рядом с шахматами. Партии,
сохранённые позиции и остальные приложения сохраняются. Затем безопасно отключи USB.
Обычная распаковка ZIP не регистрирует значок в «Играх» — это необязательный шаг.
Подробнее об ограничениях и восстановлении: [интеграция с меню](desktop-integration.md).

Для проверки скачанных файлов также приложен `SHA256SUMS.txt`:

```sh
sha256sum --check --ignore-missing SHA256SUMS.txt
```

Если новая ассоциация ещё не делает SGF видимыми в штатной библиотеке, используй файловое
меню Era-SGF и сообщи модель/версию прошивки. Поведение сканера библиотеки и передача пути
новому обработчику должны быть подтверждены на конкретной прошивке.

Действие ассоциации в приложении добавляет `era-sgf.app` в `system/config/extensions.cfg`,
сохраняя остальные форматы и другие SGF-программы. Перед изменением существующий файл
копируется в `extensions.cfg.era-sgf.bak` (или следующий свободный номер).
Символическая ссылка вместо конфигурационного файла не перезаписывается.

При обновлении с 0.1 удали старые `applications/era-sgf-install.app` и
`applications/era-sgf-uninstall.app`: отдельные ярлыки больше не поставляются,
обе операции доступны в меню единственного приложения.

## Библиотека партий

Положи SGF в `sgf/` в корне памяти, при желании — в подпапки по годам.
«Меню → Библиотека партий» открывает постоянный каталог с фильтрами:

- **Все**, **Новые**, **Просмотренные**. Простое открытие не отмечает партию просмотренной;
  отметка появляется после перехода к последнему узлу выбранной ветки либо вручную через меню.
- **Год** — дата партии из SGF, а при её отсутствии — год в имени файла.
- **Поиск** — игрок, турнир, дата или имя файла; регистр латиницы и русских букв не важен.

После копирования или внешнего изменения файлов нажми **⋯ → Обновить список партий**.
Там же доступны открытие SGF из папки и сброс поиска/фильтров.
Стрелки внизу или кнопки книги листают страницы. Стрелка **←** возвращает
к предыдущему меню, **×** закрывает библиотеку/меню к доске. Во всех меню стрелка находится слева в заголовке, название — по центру, крестик — справа.
Аппаратная кнопка Back также возвращает на уровень выше. В главном меню обе кнопки
заголовка возвращают к доске. Клавиатуры и подтверждения остаются системными диалогами.
После выбора года или возврата из него библиотека показывает актуальный фильтр.

**Случайная новая партия** в главном меню и **Случайная новая** в библиотеке
обновляют каталог и выбирают непросмотренный файл по всей библиотеке, независимо
от поиска и года. Одно открытие не ставит отметку просмотра. Если все партии уже
просмотрены, появляется соответствующее сообщение и текущая партия остаётся открытой.
Пустая библиотека и непрочитанные повреждённые файлы имеют отдельные сообщения.
Обычный просмотр использует сохранённый каталог и не сканирует папки в фоне.
Каталог хранится в `system/config/era-sgf/library.db`. Нечитаемая запись отмечается
отдельно и не скрывает остальные игры. В библиотеку также входят два учебных примера.

В «Текущая партия → Файл и отметка просмотра» есть отметка новой/просмотренной, перенос в
`sgf/viewed/<год>/` и удаление SGF из памяти книги. Перенос и удаление требуют подтверждения.
Перенос сохраняет байты и текущую позицию, при совпадении имени добавляет номер;
существующий файл не заменяется. Если SGF был заменён после открытия, его нужно открыть
заново перед удалением или переносом.

## Управление

- Кнопки перелистывания: предыдущий/следующий узел записи, включая узлы с комментариями.
- Строка под доской: начало, −10 ходов, номер хода, +10 ходов и конец выбранной ветки.
  Нажатие на номер открывает цифровую клавиатуру. Номер 0 возвращает к началу;
  неверное значение или отмена не меняют позицию. При прыжке считаются ходы, включая пасы;
  промежуточные узлы только с комментариями не увеличивают номер.
- «Ветки»: список продолжений. При нескольких вариантах первые десять отмечаются числами на доске.
- «Текущая партия → Навигация»: те же переходы и возврат к предыдущей развилке.
- Нажатие на текст комментария или соответствующий пункт меню: чтение на весь экран.
  В этом режиме кнопки листают страницы комментария; «Доска» или аппаратная Back возвращают к доске.
- «Текущая партия → Выбрать партию»: игры внутри SGF-коллекции.
- Кнопка `i` слева вверху: игроки, дата, результат, коми и общий комментарий.
- «Настройки → Повернуть экран»: ручная смена ориентации.
- **Авто**: автолистание, повторное нажатие **Стоп** останавливает его.
  Начиная с 1.0.2, на время проигрывания отключаются автоматическая блокировка и
  выключение. При принудительном сне (обложка/кнопка) позиция сохраняется;
  после возврата в приложение следующий ход показывается через выбранную паузу.
  Во сне ходы не пропускаются. «Стоп», меню, развилка и конец партии возвращают
  обычное энергосбережение. Системные настройки таймаутов не изменяются.
  В «Настройках» выбирается пауза 1, 2, 3, 5, 10, 15, 30 или 60 секунд; по умолчанию — 3.
  На развилке и в конце записи оно останавливается. Ветку нужно выбрать вручную.
  Ручная навигация, меню, скрытие приложения и поворот также останавливают таймер.
- **Снимок позиции (.png)**: сохраняет доску и подписи игроков в `screenshots/Era-SGF/`.
  Повторный снимок получает отдельное имя; ход и исходный SGF не меняются.
- **Настройки → Логотип при запуске**: семь вариантов из [подборки](logos/README.md), выбор сохраняется.

Позиция и ручная кодировка сохраняются при закрытии, скрытии приложения или переходе к другому
файлу. После замены содержимого SGF сохранённая позиция сбрасывается. Исходные SGF не изменяются.
Если сохранение не удалось, выход всё равно завершается, предыдущий рабочий файл состояния
остаётся доступным; причина записывается в `system/config/era-sgf/diagnostics.log`, если запись возможна.

## Кодировки

«Авто» сначала учитывает SGF `CA[...]`. Если его нет, проверяется UTF-8, затем применяются
осторожные эвристики для русских однобайтных кодировок. Для неоднозначного текста используется
стандартный SGF-вариант ISO-8859-1 с отметкой неопределённости.

Если комментарий нечитаем или `CA` указан неверно, открой «Настройки → Кодировка» и выбери UTF-8,
Windows-1251, KOI8-R, CP866, ISO-8859-5 или ISO-8859-1. Ручной выбор имеет приоритет над `CA`.
«Авто» отменяет его. В SGF-коллекции переход к другой партии снова учитывает её собственный `CA`.

Кодировки UTF-16/32 и дополнительные восточноазиатские однобайтные/многобайтные кодировки
в первоначальную версию не входят. Неподдерживаемое объявление или неверные байты отображаются
как ошибка с возможностью выбрать поддерживаемую кодировку; приложение не переписывает файл.

## Удаление и откат

Сначала выбери «Настройки → Ассоциация SGF → Удалить ассоциацию Era-SGF».
Удаляется только обработчик Era-SGF; другие SGF-обработчики остаются. Затем можно удалить
файл `applications/era-sgf.app`, два `applications/icons/era-sgf*.bmp` и учебную папку `Books/Era-SGF/`.
Если использовался host-установщик, убери только `U_EraSGF` из `applications` и списков
`view.groups[].apps` в `system/config/desktop/view.json`, сохранив остальные записи.

Настройки просмотра остаются в `system/config/era-sgf/`; их можно удалить отдельно.
Резервные копии ассоциаций сохраняются рядом с `extensions.cfg`. Восстановление целой копии
заменит и более поздние изменения других программ, поэтому для обычного удаления предпочтителен
штатный пункт удаления ассоциации.

## English quick start

Use the [host installer](desktop-integration.md) for a Book icon beside Chess in Games.
Extracting the ZIP into USB storage installs the app without this desktop registration.
Eject safely and launch Era-SGF. Use File → Open SGF
to test the bundled examples. Use the association item in the app's menu to register `.sgf` files;
the existing configuration is backed up. Close and reopen the stock library and test opening
an SGF from there. Stock-library recognition of SGF and compatibility with other models require firmware-specific checks.

The UI is currently Russian. Page-turn keys navigate nodes, the Branches button selects a
variation, tapping a comment expands it, and Settings → Кодировка changes encoding.
Use the menu's association removal action before deleting the single application file.
The library supports all/new/viewed, year and search filters. Autoplay defaults to 3 seconds,
stops at branches, and is cancelled on menu/hide/manual navigation. PNG screenshots go to
`screenshots/Era-SGF/`; seven launch marks are available in the menu. See [build.md](build.md)
and [validation.md](validation.md) for the build profile and current limits.

Игроки указаны одной строкой `B: имя (ранг) - W: имя (ранг)`.
Последний камень отмечен контрастной точкой; после паса точки нет.
Для возврата на уровень выше нажми стрелку **←** слева в заголовке; крестик **×**
справа закрывает меню к доске. В меню кнопки листания выбирают строку, OK открывает её.
Длинные списки можно листать стрелками внизу; при повороте сохраняется видимая позиция.

## Очистка экрана

В «Настройки → Обновление экрана» выбирается полная очистка через 5, 10, 20, 50 изменений
или только вручную при листании. По умолчанию 10. Считаются реальные изменения,
включая страницы комментария; нажатие в конце партии без изменения не считается.
Кнопка с круговой стрелкой справа вверху полностью обновляет экран и сбрасывает счётчик.
После меню, клавиатуры, возобновления приложения и поворота полное обновление сохраняется.
Обычная навигация между очистками использует PartialUpdate; при неподвижном экране
нет таймера и периодических обновлений. Ручной режим может оставлять следы снятых камней;
для очистки нажми круговую стрелку. Это настройка InkView, не реализация Snow Field.

## Информация и результат

Кнопка `i` слева вверху открывает сведения о партии. Тап по комментарию открывает
полноэкранный просмотр с листанием; «Доска» или аппаратная Back закрывают его.
Стрелки под доской переходят в начало, на 10 ходов назад/вперёд и в конец; тап
по номеру хода открывает ввод номера.

В конце основной линии под номером хода появляется результат из `RE`, если он
указан в SGF. Конец побочной ветки не считается завершением сыгранной партии.
Счёт не вычисляется программой. Меню → Настройки → О программе показывает версию,
автора, ссылку на исходники и сведения о лицензиях; закрытие возвращает в настройки.
