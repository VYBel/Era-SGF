# Каталог по запросу и быстрый запуск

Запрос: открывать отдельный SGF и последнюю позицию без ожидания всего каталога;
добавлять ранее неизвестный файл в библиотеку; без автоплея не выполнять фоновую
работу и не мешать энергосбережению.

В журнале Era 700 загрузка 117 309 записей занимает 39–40 с. В 1.2.1 нет
автоматического сканирования готового архива, но база читается при каждом запуске.

Выбранный способ реализации: загружать базу только для библиотеки, случайного
выбора и операций, требующих всего каталога. Пользователь разрешил вариант с
явной командой вместо фона; выбор в пользу отсутствия фона сделан для экономии
энергии. Фоновая загрузка оставляла бы процесс активным после появления доски.
Дисковый индекс/SQLite потребовали бы отдельной миграции и не нужны для этого исправления.

Открытый файл регистрируется отдельной атомарной записью в `library.pending/`:
метаданные, отпечаток содержимого и необязательная явная отметка просмотра.
Обычное открытие не сбрасывает существующую отметку. Полный каталог объединяет
эти записи при явной загрузке, фиксирует журнал/снимок до удаления очереди и синхронизирует
удаление. Повтор после прерывания должен быть идемпотентным. При ошибке данные
остаются на диске. Старые версии не читают очередь до её объединения новой версией.

По ассоциации SGF сразу появляется доска. При обычном запуске короткая заставка
сохраняется, но чтения базы за ней нет. Библиотека загружается с прогрессом;
отмена возвращает к просмотру. Обход SGF выполняется только командой обновления.
В статическом просмотре нет таймеров, фоновых сканов, запрета блокировки/выключения;
обработчики событий и завершённые callbacks возвращают управление в ForcingSleep.

Проверки: прямое открытие с большой/повреждённой базой, сохранение и объединение
одиночных регистраций и отметок, отмена загрузки, сон, отсутствие таймеров и
обращений к большой базе при просмотре. Физическая лампочка проверяется на книге.

## Уточнение для выпуска 1.2.4

Случайный выбор больше не требует полного каталога: добавлен производный индекс
`library.random` с наложением журнала и отложенных отметок. Полные метаданные
по-прежнему нужны библиотеке с фильтрами и операциям переноса/удаления.
Индекс создаётся при явном обновлении. При отсутствии индекса предлагается
обновить список; автоматического сканирования нет. Поиск ограничен 32 проверками
и мягким бюджетом 250 мс между проверками файлов.
