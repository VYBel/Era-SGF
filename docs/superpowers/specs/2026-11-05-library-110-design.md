# Era-SGF 1.1.0: библиотека и меню

Пользователь поручил самостоятельно переработать интерфейс, добавить случайную
непросмотренную партию, показать реальные скриншоты, установить сборку и отправить
изменения в GitHub. Выбор деталей интерфейса делегирован разработчику.

## Подход
Рассмотрены сохранение всего каталога в OpenMenu, полная замена всех системных меню
и отдельный экран библиотеки с короткими системными меню. Выбран последний вариант:
каталогу нужны просторные строки и постоянные фильтры, а редким настройкам достаточно
проверенных InkView-диалогов. Новых зависимостей нет; C++14/InkView/B288.

## Поведение
- Главное меню: библиотека, случайная новая партия, текущая партия, PNG-снимок,
  настройки, выход. Файловые операции — внутри текущей партии; открытие файла также
  доступно из библиотеки. При отсутствии партии остаётся прямое открытие SGF.
- Библиотека — полноценный экран: заголовок, счётчик, вкладки Все/Новые/Просмотренные,
  поиск и год, строки игроков и даты/турнира/статуса. Результат партии скрыт.
  Наверху отдельные стрелка назад и крестик закрытия. Внизу страницы и быстрый
  случайный выбор; кнопки книги листают страницы. Количество строк зависит от экрана.
- Короткое меню библиотеки: обновление списка, открытие SGF, сброс фильтров.
  Возврат из выбора года сохраняет страницу, изменение фильтра сбрасывает её.
- Стрелка ← возвращает на один уровень; закрытие/отмена системного меню возвращает к доске.
  Физическая Back на собственном экране библиотеки возвращает главное меню. В системных меню
  вместо `< Назад` используется `←`. После выбора паузы/обновления/кодировки
  возвращаемся в настройки, а не выбрасываем пользователя на доску.
- Случайный выбор равновероятен среди исправных непросмотренных файлов всей
  актуализированной библиотеки. Не зависит от поиска/года. Просмотренность остаётся
  прежней: достижение конца или явная отметка; одно открытие не отмечает просмотр.
- Различаются пустая библиотека, все просмотрены, непросмотренные повреждённые файлы.
  При отсутствии кандидата текущая партия сохраняется.
- Исправления сна/хоси 1.0.2 сохраняются. Никаких фоновых обходов библиотеки и таймеров.
